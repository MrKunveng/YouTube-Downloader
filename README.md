# 🎥 YouTube Downloader

Download videos or extract audio from YouTube with a beautiful, modern interface.

## Features

- 📥 Download videos in multiple qualities (240p to 1080p)
- 🎵 Extract audio as MP3
- ⚡ Fast and efficient downloads
- 🎨 Clean, modern UI
- ☁️ Works in the cloud

## How to Use

1. Paste a YouTube URL
2. Select video or audio
3. Choose quality (for videos)
4. Click Download!

## Technical Details

- Built with Streamlit
- Uses yt-dlp for downloads
- Requires ffmpeg for audio extraction

## Deployment

This app is deployed using Docker to ensure ffmpeg is available.
